<h2>买之前先分清三种「原生服务器」</h2>
<p>第一种：服务器带一个归属显示为原生住宅的地址。第二种：服务器带原生机房地址，只是归属清晰。第三种：服务器本身在本地，但通过线路接到原生住宅出口。</p>
<p>三种价格差别很大，能力也不同。第一种最符合「原生住宅」的预期；第二种只是归属清晰，属性上仍是机房；第三种介于两者之间。下单前问清是哪一种，比看配置表更重要。</p>

<h2>配置参数逐项说</h2>
<p>CPU：这类服务器主要做转发与出口，一两核够用。内存：随并发连接增长，是最容易低估的一项。硬盘：系统加日志，几十 G 够用，但要留日志空间。</p>
<p>带宽：按峰值并发估，注意是否限量。上行：常被忽略，做上传类业务必须确认。网卡：多出口场景需要数量足够。系统：选常用发行版，便于排障与找资料。</p>

<h2>购买流程五步</h2>
<p>第一步，定用途与地区。第二步，选配置并确认地址属性。第三步，确认条款允许的使用范围。第四步，小量下单并验收。第五步，配好环境、观察一段时间再扩。</p>
<p>第三步常被跳过。原生住宅类产品通常对使用有额外限制，比如不允许对外提供公开服务。下单前读一遍，能避免付款后被限速。</p>

<h2>三条不要买的配置</h2>
<p>一是「高 CPU 低内存」。转发用不上强算力，内存不足会在并发上来时直接卡死。二是「大带宽小硬盘」。日志写满会导致服务异常，而硬盘扩容比带宽便宜得多。</p>
<p>三是「多地址但单网卡且不支持策略路由」。地址拿了用不起来，等于白买。下单前确认设备是否支持按来源分流。</p>

<h2>三条必须确认的条款</h2>
<p>一是可否自建服务，以及允许的范围。二是流量政策，超量是限速还是加收，单价多少。三是地址不可用时的处理方式与时效。</p>
<p>三条都在条款里，但很少有人在付款前读完。花十分钟看一遍，比事后争论有效。</p>

<h2>验收与上线</h2>
<p>验收四项：归属与类型是否符合预期、是否独享、带宽与标称是否一致、连续几天是否稳定。四项都过再正式使用。</p>
<p>上线后配置三件事：改默认远程端口并启用密钥登录、关闭不需要的服务、限制管理入口来源。这三件属于基础加固，省掉会带来长期隐患。</p>

<h2>价格怎么判断</h2>
<p>把价格拆成两块：服务器配置的市价、地址属性的溢价。两块分开看，才知道自己多花的钱买到了什么。</p>
<p>如果配置报价明显高于同类，而地址属性又没有可验证的证据，那这笔支出就缺乏支撑。反过来，如果地址属性可查、独享、稳定，溢价有依据。</p>

<h2>先想清楚「这台机器上要不要放东西」</h2>
<p>只做出口的机器，配置可以压到最低，钱花在带宽和地址上；要在上面跑应用、存东西的机器，配置就得往上走。这两类需求的最优配置差得很远，混着考虑很容易两边都不合适。</p>
<p>判断标准很简单：机器重启后，除了网络服务之外还有没有别的东西需要恢复。没有，就是纯出口；有，就按应用服务器来配，别省内存和硬盘。</p>
<h2>常见问答</h2>

<p><strong>答：</strong>看用途。纯做出口低配即可，钱花在带宽与地址上更有效。</p>
<h3>能自己装软件吗？</h3>
<p><strong>答：</strong>多数可以，但要确认条款允许范围。</p>
<h3>怎么确认是原生？</h3>
<p><strong>答：</strong>查运营商标识与 ASN，核对是否为当地真实宽带商。收货后自己查一遍。</p>
